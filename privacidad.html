Política de privacidad

CotizaFlow · Actualizada el 20 de octubre de 2026

Responsable: Sequeidau Labs SpA (Chile). Contacto para consultas y derechos de datos personales: soporte@sequeidaulabs.com.

1. Información utilizada

CotizaFlow permite registrar clientes, presupuestos, servicios, datos de contacto y montos que el usuario introduce voluntariamente. La herramienta guarda la información del editor en el almacenamiento local (localStorage) del navegador. Estos registros pueden contener información personal de clientes; ingrésala solo si tienes una base legítima para tratarla.

2. Cuenta y respaldo opcional

La función de respaldo en la nube es opcional: requiere crear una cuenta o iniciar sesión. Cuando eliges expresamente subir una copia, se envían los datos del respaldo a Supabase para almacenarlos asociados a tu cuenta, según los controles de acceso implementados. El respaldo remoto no es automático y no sustituye tu propia copia JSON. Para iniciar sesión se trata tu dirección de correo y la información técnica necesaria para autenticación y seguridad.

3. Finalidades y proveedores

Utilizamos esta información para ofrecer el editor y el respaldo elegido, autenticar cuentas, prevenir abuso, atender soporte y realizar verificaciones técnicas. La aplicación está publicada a través de GitHub Pages; Supabase presta autenticación y almacenamiento remoto cuando se utiliza esa función. Los proveedores pueden procesar información fuera de Chile.

4. Cobros

La suscripción Pro está en preparación y los cobros reales no están habilitados. Si en el futuro activamos pagos a través de Mercado Pago u otro proveedor, informaremos claramente el precio, las condiciones y el tratamiento de los datos necesarios antes de aceptar una compra. No ingreses datos de tarjeta en CotizaFlow.

5. Conservación, seguridad y eliminación

Los datos locales permanecen en el navegador hasta que los elimines o el navegador borre su almacenamiento. Puedes exportarlos a JSON o eliminarlos desde Ajustes. Borrar datos del navegador no borra automáticamente los respaldos que hayas subido a la nube. Para solicitar acceso, corrección o eliminación de información asociada a tu cuenta, escribe a soporte; puede ser necesario verificar tu identidad para proteger los datos.

6. Derechos y cambios

Puedes consultar por acceso, rectificación, eliminación y otros derechos aplicables escribiendo a soporte@sequeidaulabs.com. Los cambios relevantes en las funciones o el tratamiento de datos se reflejarán en esta página. Este documento es informativo y no reemplaza las obligaciones legales de cada negocio respecto de los datos de sus clientes.

Consejo: exporta periódicamente un respaldo JSON y evita introducir datos personales innecesarios de tus clientes.
